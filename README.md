# MIS Scholar Calendar

A lightweight 2026 conference calendar for MIS scholars. The app groups conference-level events and lets users select specific dated items before exporting an `.ics` file or CSV.

## Run locally

```bash
npm install
npm run dev
```

## Seeded sources

The initial 2026 seed includes official pages for AIS conferences, WITS, INFORMS Annual Meeting, and CHITA. Conference information changes frequently, so the app displays a disclaimer and keeps source URLs attached to event groups and exported calendar entries.
